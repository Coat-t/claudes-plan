## Inside every topic file

Learning goals, prerequisites, key terms, explanation, worked example, visual, common mistakes, "Try it yourself" activities, explained answers (in collapsible blocks), an optional extension (clearly marked as optional), connections to other topics, and sources.

## Conventions

- **Spelling and terms:** US spelling and one consistent set of terms throughout (see the Key terms table in each topic, and the glossary in the study guide).
- **Made-up numbers:** every invented figure is labeled "illustrative (made-up)".
- **Diagrams:** all were created for this module. They have a white background so they display correctly in dark mode, and they include a text title and description for accessibility.
- **Verification:** calculations, puzzle solutions and probability tables were checked by script. Claims were checked against the sources cited, and any fact confirmed only through a secondary source is noted in [gaps-and-open-issues.md](gaps-and-open-issues.md).
