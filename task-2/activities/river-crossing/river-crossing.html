Mission: Get Everyone Across the River

Pixel's AI Field Guide · Curiosity Lab supplement · Version 1.0 (2026-11-06)

[MISSION BRIEF] Dr. Ada Okafor has a classic puzzle for Pixel. A farmer must take a wolf (W), a goat (G) and a cabbage (C) from the left bank to the right bank. The boat holds the farmer (F) plus at most one passenger, and only the farmer can row.

The two safety rules: if the farmer is not there, the wolf eats the goat, and the goat eats the cabbage.

How to play: press an item on the farmer's bank to put it in the boat (press it again to take it out), then press Row the boat. Every button works with the keyboard (Tab to move, Enter or Space to press).

Notation: a state is written (left bank | right bank). The start is (FWGC | -) and the goal is (- | FWGC). A dash means "nobody here".

    3. Watch Pixel search (breadth-first search)

    [OBSERVE] Pixel does not guess. It keeps a frontier (a queue of states it has found but not yet looked at) and a visited set (every state it has already found, so it never goes round in circles). Each step, Pixel takes the first state from the frontier, tries all four possible crossings (farmer alone, with the wolf, with the goat, with the cabbage), and adds any new, valid states to the back of the queue. This is called breadth-first search (BFS): it looks at all 1-crossing states, then all 2-crossing states, and so on, so the first plan it finds uses the fewest crossings.

    [LAB NOTE] This is a toy model. It assumes perfect information, instant crossings, animals that always behave the same way and exactly one goal. Real planning problems (delivery routes, robot motion) have huge numbers of states, uncertainty and costs, so AI systems use smarter search (for example A* with a heuristic) instead of looking at every state. Pixel's search here is a rule-based, search-based method: no learning from data is involved.
